# 相对 GitHub a09d51b 的最终代码改动

基准为 a09d51b48ff7ac02b127e0fdcf0cc530f9ead90d；是已下载核对的上游版本，不是未经验证的作者原图版本。

## 五个修改过的上游源码文件
- src/market/engine/match_engine.py：在撮合结束后采样独立审计字段，读取真实成交及当前订单簿，不修改成交规则或 public_info。
- src/market/data_recorder.py：单股票市场 CSV 增加真实成交价、累计最近成交价、撮合后 bid/ask/midpoint 和陈旧标记。
- src/market/engine/services/order_processing_service.py：将直接 random.shuffle 改成可注入 rng.shuffle；legacy 仍使用全局 random，受控模式注入独立实例。
- src/market/state/services/dividend_service.py：支持独立 RNG / 固定路径的分红获取，增加支付事件记录及受控模式重复支付校验；原分红模型和原支付账户逻辑保留。
- src/run_base_sim.py：运行前校验并配置分红控制，记录运行 manifest 和源码快照，运行后导出实际支付事件及路径校验；失败状态单独记录。

## 新增模块
- src/replication_audit.py：统一价格快照、代码哈希、依赖/参数/接口记录和源码快照。
- src/dividend_controls.py：legacy / independent / replay 模式、路径生成与验证、实际支付核对。
- src/valuation_audit.py：按 run-agent-round 去重，估值误差、角色统计、有效限价报价差距。
- src/figure7_report.py：结果报告与科学图表导出。
- src/llm_config.py：OpenRouter 接口及 GPT-4o 快照（初期配置阶段新增）。
- replicate.py：本地启动入口，正式/试跑和分红控制选项；并发 2 等覆盖设置。
- scripts/audit_replication.py、audit_dashboard.html：离线审计及长期网页。
- scripts/prepare_dividend_path.py、verify_dividend_isolation.py：离线路径准备和随机数耦合演示。
- tests/test_replication_audit.py、test_dividend_controls.py、test_valuation_audit.py：新增测试。
- .command 启动辅助、中文说明、audit 输出与备份：本地操作与交付资料。

## 行为边界
原撮合优先级、部分成交、成交价格计算、无成交时的报价回退、角色原始提示词和 paper 场景参数没有改变。新的独立/重放模式会改变随机流或实际分红路径，进而可能改变交易结果，必须标记为受控扩展实验。默认仍是 legacy。
旧 last_trade 字段覆盖问题没有被直接修复，避免悄悄改变 agent 输入；新增独立真实成交字段用于分析。新模式仅支持平稳单股票且无因子冲击。

最近一次修改仅影响网页：增加估值区运行选择器、修复窄屏图表与导航遮挡。浏览器本机验收已进行，未调用 GPT。
