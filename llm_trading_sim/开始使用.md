# GPT-4o 论文复现环境

本目录是桌面原始代码的独立副本。接口为 https://openrouter.ai/api/v1，模型固定为 openai/gpt-4o-2024-11-20；论文未明确具体快照，因此不能声称是作者原始快照。现有 paper_ 场景也是较新代码中的实现，不保证与 2025 年原代码完全一致。

1. 在 OpenRouter 创建密钥并配置 API 计费。
2. 双击 `1_设置密钥.command`，粘贴密钥后回车。输入不显示，保存到本目录 .env，不发往聊天。
3. 双击 `2_检查配置.command`，此步骤不调用 API。
4. 双击 `3_两轮试跑_产生API费用.command`，运行高估组 8 个交易者、2 轮，约 16 次决策请求，重试可能增加调用。请先确认 API 额度。

如 macOS 阻止双击脚本，可在终端进入本目录后运行 `.venv/bin/python replicate.py key`、`check` 或 `pilot`。

正式实验（付费）：`.venv/bin/python replicate.py above` 和 `.venv/bin/python replicate.py below`。各 15 轮。先检查 pilot 输出有效，再正式运行。

结果保存在 logs/replication_pilot、logs/replication_above、logs/replication_below 下。

基础设置：基本面 28；高估初价 56；低估初价 14；四种角色各两人；当前 paper_ 场景给做市商 20 倍初始现金和股票。温度 0、种子 42 继承场景；API 并发设为 2、最多尝试 2 次。固定种子并不保证远程模型完全确定。

试跑只验证连通和输出；完成两组正式实验与重复模拟、检查错误和成交后才能评估论文结论。

OpenRouter 配置仍沿用 OPENAI_API_KEY 环境变量保存密钥，这是兼容客户端的变量名；实际请求发送到 OpenRouter。费用以 OpenRouter 账单为准，原程序费用估计可能不识别带 openai/ 前缀的模型。
